# パブコメ掲示板 市区町村版

市区町村が意見を募集している「パブリックコメント」を、各市区のホームページから毎日集めて、
締切が近い順の一覧ページを作る仕組みです。公開先は https://yumaki5555.github.io/pubcome/city/ です。

いまは**政令指定都市20・中核市62・東京23区と、人口20万人以上の市29の計134か所**を見回っています（人口は総務省「住民基本台帳に基づく人口」令和8年1月1日現在。2026-11-08 に一般市を追加）。
人口20万人以上でも、市原市・加古川市・茨木市はホームページの作りの都合で自動では読めないため、`areas.json` の `unsupported` に理由つきで入れています（一覧ページと入口サイトでは「自動では集められず」と表示）。
府中市は追加時点で募集中の案件がなく、案件が出たときに一覧ページへ並ぶかは未確認です。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `areas.json` | 134市区の「パブコメ一覧ページ」の住所。市区を増やすときや、サイトが変わって取れなくなったときは、ここを編集する |
| `fetch.py` | 各市区のページを見回って、募集中の案件を `data.json` に保存する（読み取りのしくみは都道府県版と共通） |
| `build.py` | 一覧ページ `../docs/city/index.html` と、案件ごとのスマホ用まとめ `../docs/city/p/番号.html` を作る（ページの作り方は都道府県版と共通） |
| `config.json` | サイト名・説明文・言葉（「市区のページ」など）の設定 |
| `plain_titles.json` | 案件番号 → わかりやすい名前。毎朝のクラウド作業が書き足す |
| `missing_plain.py` | わかりやすい名前がまだない案件の一覧を出す |

## 動かし方（パブコメ フォルダで）

```
python 市区町村レベル/fetch.py
python 市区町村レベル/build.py
```

一部だけ試すときは `python 市区町村レベル/fetch.py 札幌市 港区` のように名前を付けます。

## 市区町村を増やすには

`areas.json` の `areas` に `{"name": "〇〇市", "pref": "〇〇県", "kind": "一般市", "url": "パブコメ一覧ページの住所"}` を足します。
