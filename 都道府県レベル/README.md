# パブコメ掲示板 都道府県版

47都道府県が意見を募集している「パブリックコメント」を、各県のホームページから毎日集めて、
締切が近い順の一覧ページを作る仕組みです。国版（ひとつ上のフォルダ）の姉妹版です。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `prefectures.json` | 47都道府県の「パブコメ一覧ページ」の住所。県のサイトが変わって取れなくなったら、ここを書き換える |
| `fetch.py` | 各県のページを見回って、募集中の案件を `data.json` に保存する |
| `build.py` | 一覧ページ `../docs/pref/index.html` と、案件ごとのスマホ用まとめ `../docs/pref/p/番号.html` を作る（まとめには、県のページから自動で抜き出した資料・意見の出し方・問い合わせ先を載せる） |
| `config.json` | サイト名・説明文・公開アドレスなどの設定 |

注目テーマ（外国人政策・子育てなど）は、国版と同じ `../keywords.json` を使います。

## 動かし方

```
python fetch.py
python build.py
```

`../docs/pref/index.html` をダブルクリックすると一覧ページが見られます。
一部の県だけ試すときは `python fetch.py 東京都 大阪府` のように県名を付けます。
`DEBUG=1` を付けて動かすと、どのページを見て何と判断したかが表示されます。

## しくみ（国版との違い）

国は e-Gov という1つのサイトにまとまっていますが、都道府県は47個のサイトがバラバラの作りです。
そこで次のやり方で、どの県にも共通に読み取っています。

1. `prefectures.json` の一覧ページを開く
2. 「令和8年度」「募集中」などの一覧があれば、1〜2段奥まで開く
3. 案件らしいページを開き、「募集期間」「締切」などの近くにある日付から締切日を読み取る
   （一覧表の各行に期間が書いてある県は、表から直接読み取る）
4. 「意見募集」「パブリックコメント」などの言葉がないページ（職員募集・補助金など）は外す
5. 締切前で、募集がすでに始まっているものだけを載せる

一度見た案件ページは `data.json` に覚えておき、毎日すべてを開き直さないようにしています。

## 限界

- 県の一覧ページに載っていない案件（報道発表だけのもの等）は拾えません
- ページの作りによっては、締切日を読み取れない・まちがえることがあります
- 県のサイトが引っ越すと取れなくなります。0件が続く県は `prefectures.json` の住所を確認してください
